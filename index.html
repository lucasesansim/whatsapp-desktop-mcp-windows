A Regra de Ouro: Anexo Primeiro, Texto Depois

Durante o desenvolvimento de fluxos automatizados com IA, identificamos que ao compartilhar arquivos pesados (pranchas executivas em PDF, renders 3D em alta resolução, planilhas ou relatórios técnicos), a ordem dos fatores muda completamente a estabilidade da entrega.

Fluxo Correto (Anexo Primeiro)
  1. 1. Executa send_file: O MCP abre a conversa, injeta o documento via input nativo do WebView2 e utiliza o campo caption para a legenda.
  2. 2. Processamento e Âncora: O WhatsApp carrega o arquivo e fixa o card como âncora principal na conversa.
  3. 3. Texto Complementar (Opcional): Se houver explicações adicionais, o send_message é disparado em seguida, posicionando o texto logo abaixo do arquivo.
Fluxo Evitado (Texto Primeiro)
  • • Enviar o texto antes força o cliente a ler uma mensagem solta sem o documento referenciado.
  • • Pode provocar perda de foco no campo de anexo caso o usuário ou bot interaja enquanto o upload ocorre.
  • • Gera mensagens picadas e descontextualizadas no histórico do cliente.

Catálogo Completo de Ferramentas

10 ferramentas prontas para uso por qualquer agente conectado via Model Context Protocol.

send_file Escrita

Envia relatórios PDF, renders e documentos em resolução 100% original com legenda opcional.

send_message Escrita

Envia mensagens de texto formatadas com validação de destinatário e proteção contra envios acidentais.

list_chats Leitura

Lista conversas recentes (1:1 e grupos) ordenadas por atividade recente, com mensagens não lidas.

read_chat Leitura

Lê o histórico de mensagens de uma conversa mais recente primeiro, com paginação por cursor.

search_contacts Leitura

Busca contatos por fragmentos de nome ou telefone para descobrir o chat_id correspondente.

extract_recent Leitura

Extrai todas as interações de uma conversa nas últimas N horas com sumário de cobertura temporal.

search_messages Leitura

Busca de texto em mensagens por substring com filtros opcionais por data e remetente.

get_chat_metadata Leitura

Recupera título do grupo, descrição, lista de membros e status de administradores.

doctor Diagnóstico

Instalação Rápida no Windows

3 etapas simples para ter o WhatsApp MCP operando no seu sistema.

1

Habilitar a Porta de Depuração do WebView2

Abra o PowerShell e execute o comando abaixo para permitir a automação local segura na porta 9224:

[Environment]::SetEnvironmentVariable("WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS", "--remote-debugging-port=9224", "User")

*Reinicie o WhatsApp Desktop completamente para que a configuração entre em vigor.

2

Clonar e Sincronizar o Ambiente

git clone https://github.com/Cristinacarolsouza/whatsapp-desktop-mcp-windows.git
cd whatsapp-desktop-mcp-windows
uv sync
3

Configurar no Claude Desktop / Antigravity

Adicione ao seu mcp_config.json:

{
  "mcpServers": {
    "whatsapp": {
      "command": "cmd.exe",
      "args": [
        "/c", "uv", "run",
        "--directory", "C:\\caminho\\para\\whatsapp-desktop-mcp-windows",
        "whatsapp-desktop-mcp",
        "--no-read-only"
      ]
    }
  }
}
