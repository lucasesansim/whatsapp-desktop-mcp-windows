WhatsApp Desktop MCP

Fork experimental para investigar la integración de WhatsApp personal con ChatIÁ.

Se corrigieron comprobaciones de destinatarios, mensajes nuevos, confirmaciones y concurrencia. Las pruebas utilizan datos ficticios. La compatibilidad y la latencia con WhatsApp real siguen pendientes.

Usa interfaces internas de la app: no es una API oficial de Meta ni elimina el riesgo de restricciones de cuenta.
